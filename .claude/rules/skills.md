# Claude Code Skills

This file applies only to Claude Code.

Use installed Obsidian skills through the Skill tool before vault work:

- `obsidian-markdown` for Markdown notes, wikilinks, embeds, callouts, and properties.
- `obsidian-cli` for Obsidian CLI work.
- `obsidian-bases` and `json-canvas` for `.base` and `.canvas` files.
- `defuddle` to extract clean Markdown from a web page.

Claude Code auto-surfaces `.claude/commands/` in its skills list; that is the live command catalog. Do not duplicate that table in an instruction file. QMD search rules remain in `AGENTS.md` because every MCP-capable agent can use them.
